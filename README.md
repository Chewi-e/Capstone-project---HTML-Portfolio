# Capstone Project 1 - Personal Portfolio & Resume

### Objective:
To build a basic, multi-page personal portfolio and resume website from scratch using fundamental HTML elements, lists, images, and internal linking to showcase background details, education, skills, and personal interests.

### Technologies Used:
* HTML5
* Basic Inline CSS styling

---

### Project Structure & Features:
* **`index.html` (Homepage / Resume):** Serves as the primary landing page containing a professional summary, profile image, education history, volunteer experience, skills, and links to secondary pages.
* **`Public/Contact.html`:** A dedicated contact page containing telephone and email details.
* **`Public/My Hobbies.html`:** A personal interest page highlighting hobbies such as hiking, creative writing, baking, and learning how to code.

---

### How to View Locally:

1. Clone or download this repository to your local machine.
2. Open the project folder in your code editor (such as VS Code).
3. Double-click the `index.html` file or open it using a live server extension in your web browser to view the site.
